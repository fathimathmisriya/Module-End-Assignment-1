# Healthcare Data Analysis and Insights

## Overview

This project focuses on analysing healthcare data using **Microsoft Excel**. The dataset was cleaned, transformed, combined and analysed to identify useful patterns related to patient health, hospitalisation and healthcare charges.

## Key Tasks

* Cleaned and handled missing data.
* Transformed and organised customer information.
* Created **Weight Status** and **Diabetes Status** categories.
* Calculated Date of Birth and Age.
* Combined multiple tables using **VLOOKUP**.
* Created PivotTables for data analysis.
* Used **Doughnut, Column and Scatter Charts** for visualisation.
* Analysed relationships between age, BMI, HbA1C and healthcare charges.
* Created an interactive **Healthcare Dashboard**.
* Added slicers for **Weight Status** and **Diabetes Status**.

## Tools Used

**Microsoft Excel** – Data Cleaning, Transformation, Analysis, PivotTables, Charts and Dashboard.

## Project Outcome

The project presents healthcare data in a structured and visual format, making it easier to understand patient characteristics, health conditions and healthcare charges.
